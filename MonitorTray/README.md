# MonitorTray - 显示器亮度控制工具

一个基于 .NET 10 的系统托盘应用程序，用于通过 ddccli.exe 控制显示器的亮度和对比度。支持游戏模式和日常模式，并可根据时间自动调整参数。

## 功能特性

- 🎮 **双模式支持**：游戏模式和日常模式，满足不同使用场景
- ⏰ **时间自动调整**：根据时间段自动切换亮度和对比度
- 📊 **托盘图标指示**：实时显示当前模式状态
- 🔄 **手动刷新**：支持手动触发设置应用
- ⚙️ **配置灵活**：通过 JSON 配置文件自定义参数

## 技术栈

- .NET 10 (Windows)
- Windows Forms (系统托盘)
- ddccli.exe (显示器控制)

## 快速开始

### 1. 编译项目

```bash
dotnet build --configuration Release
```

### 2. 配置设置

编辑 `config.json` 文件：

```json
{
  "DdccliPath": "ddccli.exe",
  "Modes": {
    "Game": [
      { "Time": "07:00", "Brightness": 75, "Contrast": 80 },
      { "Time": "18:00", "Brightness": 60, "Contrast": 70 }
    ],
    "Daily": [
      { "Time": "07:00", "Brightness": 65, "Contrast": 80 },
      { "Time": "18:00", "Brightness": 50, "Contrast": 80 }
    ]
  },
  "Hotkeys": {
    "SwitchToGameMode": "Ctrl+Shift+G",
    "SwitchToDailyMode": "Ctrl+Shift+D",
    "ManualRefresh": "Ctrl+Shift+R",
    "IncreaseBrightness": "Ctrl+Shift+Up",
    "DecreaseBrightness": "Ctrl+Shift+Down"
  }
}
```

### 3. 运行程序

```bash
# 开发环境
dotnet run

# 发布版本
bin/Release/net10.0-windows/publish/MonitorControlTray.exe
```

## 配置说明

### config.json 字段解释

| 字段                           | 类型   | 说明                                               |
| ------------------------------ | ------ | -------------------------------------------------- |
| `DdccliPath`                   | string | ddccli.exe 的路径（支持相对路径和绝对路径）        |
| `Modes`                        | object | 模式配置对象，key 为模式名称，value 为时间设置列表 |
| `Modes[modeName][].Time`       | string | 时间点（格式：HH:mm）                              |
| `Modes[modeName][].Brightness` | int    | 亮度值（0-100）                                    |
| `Modes[modeName][].Contrast`   | int    | 对比度值（0-100）                                  |
| `Hotkeys`                      | object | 快捷键配置对象                                     |
| `Hotkeys.SwitchToGameMode`     | string | 切换到游戏模式的快捷键                             |
| `Hotkeys.SwitchToDailyMode`    | string | 切换到日常模式的快捷键                             |
| `Hotkeys.ManualRefresh`        | string | 手动刷新设置的快捷键                               |
| `Hotkeys.IncreaseBrightness`   | string | 增加亮度的快捷键                                   |
| `Hotkeys.DecreaseBrightness`   | string | 降低亮度的快捷键                                   |

### 模式切换

右键点击系统托盘图标，选择「切换模式」→ 选择目标模式。

### 快捷键操作

程序支持以下全局快捷键（可在配置文件中自定义）：

| 快捷键            | 功能           |
| ----------------- | -------------- |
| `Ctrl+Shift+G`    | 切换到游戏模式 |
| `Ctrl+Shift+D`    | 切换到日常模式 |
| `Ctrl+Shift+R`    | 手动刷新设置   |
| `Ctrl+Shift+Up`   | 增加亮度（+5） |
| `Ctrl+Shift+Down` | 降低亮度（-5） |

**快捷键格式说明**：

- 支持的修饰键：`Ctrl` / `Control`、`Shift`、`Alt` / `Menu`、`Win` / `Windows`
- 支持的功能键：`Enter`、`Tab`、`Space`、`Up`、`Down`、`Left`、`Right`、`F1`-`F12` 等
- 组合键使用 `+` 连接，例如：`Ctrl+Shift+G`

### 时间规则

程序每分钟检测一次当前时间，根据配置的时间点自动应用对应的亮度和对比度：

- 如果当前时间在两个时间点之间，应用较晚的时间点设置
- 如果当前时间早于第一个时间点，应用最后一个时间点设置（即前一天的夜间设置）

## 已实现功能

### 异常处理

- ✅ **异常捕获与提示**：所有异常都被捕获，通过托盘气泡通知用户
- ✅ **错误码检测**：检测 ddccli 退出码，非零退出码时显示警告
- ✅ **静默失败处理**：关键错误不影响主程序运行

### 配置验证

- ✅ **必填项检查**：验证 DdccliPath 和 Modes 不能为空
- ✅ **参数范围验证**：亮度和对比度必须在 0-100 范围内
- ✅ **时间格式验证**：验证时间格式是否正确（HH:mm）
- ✅ **模式完整性检查**：验证每个模式至少有一个时间设置

### 错误日志

- ✅ **自动日志目录创建**：程序启动时自动创建 logs 目录
- ✅ **操作日志记录**：记录程序启动、模式切换、参数设置等操作
- ✅ **错误日志记录**：记录所有异常和错误信息
- ✅ **时间戳标记**：每条日志包含精确时间戳

### 图标支持

- ✅ **ICO 格式优先**：优先使用 `assets/icon.ico`
- ✅ **PNG 格式备选**：支持 `assets/icon.png` 作为备选
- ✅ **默认图标降级**：图标加载失败时自动使用系统默认图标

### ddccli 搜索路径

程序按以下优先级查找 `ddccli.exe`：

1. ✅ **配置指定的路径**：如果 `config.json` 中指定了绝对路径
2. ✅ **当前目录**：程序运行目录下的 `ddccli.exe`
3. ✅ **PATH 环境变量**：系统 PATH 中包含的目录

### 开机自启

- ✅ **快捷方式实现**：通过在启动目录创建快捷方式实现
- ✅ **菜单控制**：托盘菜单中提供启用/禁用选项
- ✅ **状态指示**：菜单项显示当前自启状态

### 快捷键支持

- ✅ **配置化快捷键**：快捷键可在配置文件中自定义
- ✅ **全局热键**：使用 Windows API 注册全局热键
- ✅ **多操作支持**：切换模式、刷新设置、调整亮度
- ✅ **动态重载**：重载配置后快捷键自动更新

### 菜单增强

- ✅ **亮度对比度显示**：模式名称后显示当前配置的亮度/对比度数值
- ✅ **重载配置**：添加「重载配置」菜单项，支持动态加载配置
